# Peptide Performance

Official website repository for **Peptide Performance**.

**Website:** https://peptideperformance.net

## About

Peptide Performance provides educational research information, a peptide research library, ordering information, and connections to the BUILT50 fitness community.

The website uses a black, orange, and white design and is optimized for desktop and mobile devices.

## Website Structure

- `index.html` — Homepage
- `research.html` — Research library
- `ordering.html` — Ordering information
- `about.html` — About Peptide Performance
- `faq.html` — Frequently asked questions
- `*-research.html` — Individual research information pages
- `styles.css` — Website styling
- `script.js` — Website JavaScript
- `sitemap.xml` — Search engine sitemap
- `CNAME` — Custom domain configuration
